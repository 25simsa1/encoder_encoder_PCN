# State (updated 2026-07-11)

## Current hypothesis
The text-to-image failure has been decomposed down to one hard sub-problem. Fixed/understood so far: the text path is healthy and sets the shared latent at the right scale; invertible strided-conv downsampling reconnected the generative pathway the one-way maxpools had severed; a top-down-authoritative generation schedule makes the caption drive the image per-pixel (PR 0 -> ~6). What REMAINS is amplitude: the top-down decode produces a dark, low-contrast, low-frequency image (gen brightness ~0.4x the true image, never sharp). A darkness diagnostic showed this is NOT the latent (text-set latent scale matches image-set) and NOT weight decay (decode weight-norm unchanged) -- it is the top-down PC decode producing the low-amplitude CONDITIONAL MEAN (the blurry average image consistent with the latent). The generative-training objective (two-phase: text-drive the latents, then bridge to the true image clamped at the bottom, local weight step) trains stably at a gentle schedule but does NOT sharpen -- it actually darkens over steps, because the clamped true image "helps" during the weight step so the decode never learns a strong standalone latent->image map. The generative objective was then redesigned as a contrastive-Hebbian (CHL) pass that supervises the PURE top-down decode toward the true image, but it (and every prior generative objective) DESTABILIZES at ~ep13 the same way: NORM INFLATION (the beta-less LARS trust ratio grows with ||w||, a positive feedback that inflates weights and states until the state clip and the energy explode). So the objective is not the blocker; the norm-inflation instability is, and it caps how long any generative training can run.

CURRENT FIX (in flight): a PC-native weight-normalization stabilizer. Each opt-in conv/dense weight is reparameterized w = g_mag * v/||v|| (per-output-unit magnitude + unit direction, the SAME shared weight both directions so it stays bidirectional PC), and update_wts splits the class's own local gradient into a radial magnitude step + a tangential direction step so ||w|| cannot run away; LARS trust is dropped for these layers. Opt-in via --weight-norm, byte-identical when off. RESULT (2026-07-11): the weight-norm stabilizer SHIPPED and WORKS (conv c0a4d42, dense e0ba22e, --weight-norm 45274ec, trust-fix 7d8f50e; 7 unit tests; COCO64 gate byte-identical when off, GATE_MATCH nlayers=88; NATIVE-143 gate deferred to a big-GPU window). One correction, dropping the LARS trust exploded fresh-init in one step, so trust is KEPT but on the stabilized ||v|| (both weight-norm AND trust are needed). The warm-started CHL retrain (job 8845) now trains STABLY past ep13 (energy bounded 0.07 vs the prior 7-10 blowup), with a residual energy-bounded state drift toward the clip.

BUT the make-or-break retest REFUTES the "instability is the blocker" hypothesis: with stability fixed, the CHL objective does NOT sharpen text-to-image and FLATTENS it with training (boosted-gen contrast 0.404@ep1 -> 0.243@ep12; brightness stuck at the ~0.40 conditional-mean). So the true ceiling is the GENERATIVE OBJECTIVE (squared-error PC decode converges to the blurry conditional mean; more stable training makes it flatter), NOT the training stability. The stability fix was necessary to isolate this, and the weight-norm code is a keeper for any longer generative training.

Approach A (high-frequency-weighted energy) SHIPPED and was tested: a high-pass boost on conv1's bottom pixel error (opt-in --hf-weight, byte-identical off, GATE_MATCH nlayers=88, composes with weight-norm). VERDICT = NULL over a full gamma sweep (contrast flat 0.24->0.25 across gamma 0/1/2/3; brightness stuck ~0.40). A high-pass confined to the last pixel-mapping cannot reach the blur, which is set upstream by the whole decode chain + the shared latent. This reinforces the mean-collapse diagnosis (a deterministic error-reweighting cannot beat the conditional mean). The HF code stays in the tree (opt-in, inert off) as a characterized negative.

Approach B1 (PC-native EBM by noisy relaxation) SHIPPED and was tested: opt-in Langevin noise in update_state (byte-identical off, GATE_MATCH nlayers=88) + a contrastive-divergence ebm_step (chl_step with a noisy CD-1-from-data negative phase). VERDICT = NULL. Training is stable, but generation fails: the deterministic mode is degenerate (0.28/0.13, worse than plain CHL) and SAMPLING gives pure RGB noise (samples mean ~0, std 0.5-1.3, values far outside [0,1]). The CD-1 contrast did not carve sharp energy wells, so there is no Langevin sweet spot (small noise -> blurry mode, large noise -> static). The B1 code stays in the tree (opt-in, inert off) as a characterized negative.

So the mean-collapse has now survived a deterministic error reweighting (Approach A) AND a Langevin EBM (B1). Two clean nulls. The remaining principled sampling option is the DIFFUSION flavor (B3), which explicitly learns a multi-noise-level denoiser (noise->data at each level) and is the proven cure for blurry generation, but it is the biggest lift and furthest from the current machinery.

Approach B3 (diffusion-in-PC) SHIPPED and was tested (diffusion_step over a 10-level schedule, byte-identical off, no layer change). VERDICT = NULL. Training is stable, but the direct denoiser test is conclusive: the "denoised" MSE-to-true EQUALS the noised MSE exactly at every level, so x0_hat = x_t -- the net trained into a PLAIN AUTOENCODER (reconstruct the input) and never denoises. Root cause: bidirectional PC's SHARED WEIGHTS default to reconstructing the input, reinforced by the clean-recon interleave, so the x_0 target never shifts the map off identity. Reverse diffusion from noise therefore stays noise. B3 code stays in the tree (opt-in, inert off).

THREE clean nulls now on the mean-collapse, each with a clear mechanistic reason: A (deterministic HF, can't beat the conditional mean), B1 (Langevin EBM, energy never sharpened so samples are noise), B3 (diffusion, shared weights collapse the denoiser to identity). Sharp from-scratch 64px text-to-image is proving very hard for this bidirectional-PC design, and each null pins down why.

The latent-source probe (2026-07-12) then REFRAMED the whole failure. Decoding from IMAGE-set latents (correct content at every scale) still yields only a brightness-modulated luminance template, and per-scale swaps show 4 of 5 latents are completely inert under the boosted route (only the deepest code matters, and it only sets brightness). So the binding constraint is NOT the latent content and NOT the fine-latent attenuation. The top-down decode was never trained to be top-down self-sufficient, recon always clamped the image (intermediates bottom-up), and every generative objective so far conditioned on TEXT-set latents (the ill-posed conditional-mean setup).

The latent-autoencoder CHL (fix A, --gen-latents image, job 8936) then RAN AND FAILED, and the failure completes the characterization. Even with the well-posed target (image-set latents, whose conditional mean IS the true image), the decode converged to the same low-amplitude template, now dimmer than untrained (0.53/0.26 vs 1.09/1.31). And the gamma=0 readout is the smoking gun, plain relaxation decodes EVERY latent source to exactly zero. So the root is STRUCTURAL, the top-down pathway of this shared-weight net is CONTRACTIVE (latent signal dies across the 9-layer decode without a boost) and the only revival route (the gamma=1 replacement boost) is single-chain feedforward that destroys all but the deepest code's information. Local contrastive training cannot fix it because the free phase itself collapses to zero, a degenerate negative sample.

THE CONTRACTION SWING (user-directed, the last generation lever) RAN AND IS EXHAUSTED (2026-07-13). The precision probe first corrected the record, the earlier zero-decode was RATE STARVATION (the diagnostics build at state_lr 1e-4, so relaxation from zeros barely moves) and at an adequate rate the top-down cascade EXPRESSES but is miscalibrated, a content-blind saturated output at every schedule (pi_bu 0/0.3/1.0, means 3.4-8.6, latent source irrelevant to the 3rd decimal). Then the training half, the calibration CHL with an expressing free phase, destabilized at BOTH expression levels (full = recon weights wrecked in 150 steps, gentle = accelerating degradation pinned at the clip by ep2), while the degenerate expression level (the original latent-AE CHL) merely flattens. The window between a degenerate negative and a destabilizing negative is EMPTY.

THE GENERATION QUESTION IS CLOSED AS A CHARACTERIZED NEGATIVE (pending the lead's sign-off). Campaign tally, seven generative objectives (gen, gentle-lr, CHL, HF-weighted, Langevin EBM, diffusion-in-PC, latent-AE/calibration CHL), two inference routes (the replacement boost and the precision schedules across the rate sweep), every failure with a pinned mechanism, and every mechanism's code opt-in and byte-identical off (gated). The shared-weight bidirectional-PC design at 64px cannot render latent identity top-down and cannot be trained to by any local contrast tried, and the full why is documented in the LOG.
